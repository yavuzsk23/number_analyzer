# English

# Number Analyzer

A simple C# console application that determines whether an input number is even/odd and positive/negative/zero.

# How It Works
1. Enter an integer.
2. The program prints whether the number is even or odd, along with its sign (positive, negative, or zero).





#  Deutsch

# Zahlenanalysato

Eine einfache C#-Konsolenanwendung, die bestimmt, ob eine eingegebene Zahl gerade/ungerade und positiv/negativ/null ist.

# Funktionsweise
1. Geben Sie eine ganze Zahl ein.
2. Das Programm gibt aus, ob die Zahl gerade oder ungerade ist, sowie ihr Vorzeichen (positiv, negativ oder null).


# Türkçe

# Sayı Analizörü

Kullanıcıdan alınan bir sayının tek/çift ve pozitif/negatif/sıfır durumunu belirleyen basit bir C# konsol uygulamasıdır.

# Nasıl Çalışır?
1. Bir tam sayı girin.
2. Program sayının tek mi çift mi olduğunu ve işaretini (pozitif, negatif, sıfır) ekrana yazdırır.
